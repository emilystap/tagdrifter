# Security policy

Please report vulnerabilities privately through
[GitHub's private reporting](https://github.com/emilystap/tagdrifter/security/advisories/new),
not in a public issue. Include what's affected and how to reproduce it.

Tag Drifter is a personal project, so there's no response deadline, but reports are welcome and
will be looked at. Fixes go into `main`, which publishes `ghcr.io/emilystap/tagdrifter:latest`;
older images aren't patched.
